# Statement Theme Library

This library is the reusable application narrative map for PhD, fellowship, and scholarship statements. It is designed so future packets can start from a known theme instead of rebuilding a story from scratch.

## How to use this library

1. Pick one primary theme that matches the role.
2. Pick at most one secondary theme to strengthen the fit.
3. Use the source anchors below to pull evidence from the local workspace or Overleaf mirror.
4. Keep anonymous or unpublished manuscript material in retitled sanitized form only.

## Recommended narrative order by application type

- Quantum-heavy PhD: lead with Quantum AI, then add Fairness AI or Quantum + Fairness.
- Health / bioinformatics PhD: lead with Fairness in Bioinformatics, then add Inclusion / Diversity or Quantum + Bioinformatics if the program is methods-heavy.
- Teaching / access / scholarship application: lead with Inclusion / Diversity, then add Fairness AI or Fairness in Bioinformatics as proof of transferable research depth.
- Interdisciplinary fellowship: combine Quantum + Fairness or Quantum + Bioinformatics only if the host explicitly values cross-domain work.

## Public-safe writing sample ladder

1. `GA_Dynamic_Qubit_Allocation_Report.pdf` for quantum-heavy roles.
2. `GA_iCMAB_Evaluation_Report.pdf` for bandit/methodology-heavy roles.
3. `DSCI601_Project_Proposal_Final.pdf` for fairness + quantum + clinical/biomedical framing.
4. `BIOL550-DSCI601-Quantum-Fair-Biomarkers.md` for fairness in bioinformatics or hybrid narratives.
5. `ethics_fairness_report.pdf` or the EQUITAS addendum for inclusion/diversity and AI ethics roles.

## Guardrails

- Do not reuse the exact ICNP draft title while the submission is anonymous.
- If a manuscript-style sample is needed, derive a retitled sanitized copy from `GA Papers/QuantumFaultTolerant/main.tex`.
- Keep raw transcripts, private advisor logs, and unreviewed recommendation materials out of public-facing application packets.
