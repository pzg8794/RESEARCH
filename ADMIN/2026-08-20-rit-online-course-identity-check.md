# RIT Fall 2026 Online-Course Identity Check

## Verified Requirement

- RIT notified Fall 2026 online-course students on 17 August 2026 about federal identity-verification responsibilities.
- An RIT-approved ID photo must be on file within two weeks of beginning an RIT class; this is required once during enrollment.
- Each online-course instructor must verify student identity by the end of week three, using the method specified for that course.
- Online coursework must use RIT accounts, MFA, myCourses, and RIT email.

## Action Checklist

1. Confirm that an approved RIT ID photo is already on file; submit one through the official process only if it is missing.
2. Review each Fall 2026 online course for the instructor's identity-verification instructions.
3. Complete each course-specific verification by the stated deadline and keep confirmation privately.
4. Use only RIT accounts and MFA for online-course work.

## Evidence Boundary

This record documents the administrative requirement only. It does not store identification images, credentials, or verification records.
