## Weekly Post Template

Use this template for each platform variant.

1. Hook: one sentence on problem significance.
2. Contribution: what you built, tested, or learned this week.
3. Evidence: one public-safe link (repo, paper, or project page).
4. Relevance: one sentence tying it to PhD research direction.
5. Close: one question or collaboration invitation.

## Definition of Done (every Friday)

- One core research post published.
- Two platform variants published (LinkedIn plus one of website/ResearchGate).
- One visible GitHub signal updated (profile README, pinned repo, or repo note).
- Profile links cross-checked for consistency.
- Next week topic pre-selected.
