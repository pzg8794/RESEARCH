## Working order

1. Use the roadmap to decide what needs action now.
2. Use the shortlists and canonical-status files to choose the right writing samples for the target role.
3. Use the source map to find the underlying local documents.
4. Copy only public-safe or sanitized extracts into this repo.
5. Keep raw personal, financial, identity, transcript, advisor-log, and application-form materials in the local/Drive source folders.
