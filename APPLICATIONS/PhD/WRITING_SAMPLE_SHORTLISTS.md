## Default packet rules

1. Lead with one primary sample and add only the smallest number of support samples needed to improve fit.
2. Prefer upload-ready derivatives before raw Overleaf or Drive sources.
3. Use the canonical Overleaf IDs in `OVERLEAF_CANONICAL_STATUS.md` whenever multiple similar course projects exist.
4. `DSCI633` now has a staged repo-side application copy. Prefer BIO614, DSCI601, or ISTE780 first when a polished manuscript is required; use DSCI633 when a sole-authored healthcare data-science course report is the better fit.
5. **Canonical CV order (LOCKED):** BDMD → PHRR → BIO614 → ISTE780 → BIOL550 → DSCI601 (non-quantum). QuantumPathOptimization leads for quantum CVs. Do NOT reorder.
6. BIOL550 is now a **standalone** entry — never combined with BIO614. Use the IEEE-format solo version (`biol550-ieee-ngs-reanalysis-writing-sample.pdf`) for applications.

## Shortlists

### Technical ML / Methods

- Primary: `Uppsala-2026-Writing-Sample-DSCI601-Clean` - strongest current methods/fairness writing sample.
- Secondary: `ISTE780-Project_Phase4` - best breadth sample for AI systems and interdisciplinary reporting.
- Third choice: `BIO614-FinalProjectProposal` - use when the role is ML-heavy but benefits from formal scientific writing.
- Backup after review: `DSCI644-GP-Phase4`.
- Additional backup: staged `DSCI633` report when the posting benefits from a sole-authored healthcare ML project more than manuscript polish.

### Computational Biology / Health ML

- Primary: `BIO614-FinalProjectProposal` - default lead sample for biology, genomics, and diagnostics roles.
- Secondary: `Uppsala-2026-Writing-Sample-DSCI601-Clean` - strongest methods/fairness support sample.
- Companion: `BIOL550-Project_Paper` - good biological context, usually not the first standalone upload.
- Optional breadth: `ISTE780-Project_Phase4`.
- Backup after review: `DSCI644-GP-Phase4`.
- Additional backup: staged `DSCI633` report for healthcare prediction and data-science-heavy packets.

### Responsible AI / Fairness / Governance

- Primary: `Uppsala-2026-Writing-Sample-DSCI601-Clean` - strongest technical fairness artifact.
- Secondary: `IDAI700-Research_Paper` - preferred single-paper IDAI700 sample after review.
- Broader-impact supplement: `IDAI700-Research_Portfolio` or `RIT Together Proposal`.
- Companion conceptual note: the EQUITAS / fairness-framework materials tracked in `MASTER_RESEARCH_INDEX.md`.
- Use with caution: `IDAI700-Research_Portfolio` when the application rewards lived-narrative synthesis more than conventional paper structure.
- Avoid by default: slide decks and short reflections unless the form explicitly asks for brief coursework evidence.

### Quantum / Routing / Adaptive Decision-Making

- Primary: sanitized `QuantumPathOptimization` application copy.
- Secondary: `Uppsala-2026-Writing-Sample-DSCI601-Clean` when the role also values ML methods or fairness.
- Optional breadth: `ISTE780-Project_Phase4` only if the packet benefits from interdisciplinary AI evidence.
- Hold back: anonymous-review quantum venue drafts and unsanitized manuscript titles.

### Broader Impact / Outreach / Fellowship

- Primary: `IDAI700-Research_Portfolio` - strongest current course-based ethics/outreach writing anchor.
- Secondary: `RIT Together Proposal` - community-facing supplement.
- Technical support sample: `BIO614-FinalProjectProposal` or `Uppsala-2026-Writing-Sample-DSCI601-Clean`, depending on whether the host is more biological or ML-focused.
- Do not lead with: raw reflections or unresolved group-phase artifacts.
- BIOL550 is now an acceptable standalone upload (use the IEEE-format solo version); it is no longer restricted to support-only use.
