## School-specific delta

- Rochester-specific statement with a technically coherent faculty/lab rationale.
- Exact secure portal fields and statement limit, if any.
- Final 3–4 faculty cluster based on current work and advising availability.
- Corrected academic CV.
- Current transcript set and English-waiver evidence.
- Deliberate decision about optional GRE.
- Three tailored academic recommendation packets.
