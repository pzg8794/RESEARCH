## Status vocabulary

- `SAVED / VIBER APPROVE`: candidacy is supported; the application is not yet submitted.
- `SAVED / VIBER MODIFY`: a specific inquiry, verification, or packet correction is required.
- `SAVED / VIBER SKIP`: a hard conflict was verified; do not spend more application effort unless the live posting changes.
- `SUBMITTED`: a submission receipt or confirmation was observed and separately documented.
- Never convert `SAVED` to `SUBMITTED` without authoritative confirmation.
